# i18n — локализация База

Файл `baza-ru.json` содержит маппинг ключей для замены текстов при форке upstream.

## Использование

При форке Penpot — скрипт или ручная замена строк по ключам из этого файла в исходниках frontend.

## Расширение

Добавлять новые ключи по мере обнаружения строк «Penpot» в UI.
